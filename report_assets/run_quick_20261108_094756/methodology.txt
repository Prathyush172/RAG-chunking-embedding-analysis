We conducted empirical retrieval experiments using the RFC RAG Chunking Lab evaluation pipeline on technical networking documentation (RFC 9293, RFC 1034, RFC 1035, and RFC 9110; corpus SHA-256: 847ab41c0c75...). Evaluations were executed in Python 3.11.9 using PyTorch 2.3.1 and FAISS 1.15.1 on a x86_64 CPU running Windows 11. Exact inner-product nearest-neighbour vector search was performed with top-k=5 under random seed 42. Ground-truth relevance was determined using verbatim character-span coverage with a strict 40-character threshold. Retrieval effectiveness was measured via position-aware Hit@5, Mean Reciprocal Rank (MRR), Precision@5, Recall@5, Context Precision, and Context Recall, with 95% bootstrap confidence intervals computed over 1,000 resamples. Note: This experiment included 56 draft evaluation questions awaiting human verification; findings should be considered preliminary.
